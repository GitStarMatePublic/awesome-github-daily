# Hoppscotch: the fast, open-source Postman alternative that lives in a tab — 80k stars

![hoppscotch/hoppscotch](https://opengraph.githubassets.com/live/hoppscotch/hoppscotch)

> TypeScript · MIT · 80,032 stars on GitHub

Hoppscotch is an open-source API development ecosystem — a lightweight, blazing-fast alternative to Postman that runs right in your browser. At 80k+ stars, it's the tool people reach for when Postman starts feeling heavy.

## The problem it solves

Postman got powerful and then got heavy — a whole app, an account, a login wall, sync you didn't ask for. Sometimes you just want to fire an HTTP request and read the response without a 300MB install and a sign-up.

## What I like

- Instant and lightweight — open a tab and you're testing endpoints
- Supports REST, GraphQL, WebSockets and more in one clean UI
- Open source and self-hostable, so your API collections stay yours

## One gripe

⚠️ The deepest team/enterprise collaboration features are less mature than Postman's paid tiers — solo and small-team use is its sweet spot.

## Verdict

When Postman feels like overkill for 'just test this endpoint,' Hoppscotch is the fast, open tab you'll actually keep pinned.

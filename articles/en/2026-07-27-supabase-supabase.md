# Supabase: the open-source Firebase alternative built on Postgres — 108k stars

![supabase/supabase](https://user-images.githubusercontent.com/8291514/213727234-cda046d6-28c6-491a-b284-b86c5cede25d.png#gh-light-mode-only)

> TypeScript · Apache-2.0 · 108,002 stars on GitHub

Supabase gives you a full backend — Postgres database, auth, storage, realtime, edge functions — with the developer experience of Firebase but the openness of Postgres. It's at 108k+ stars and is a default pick for shipping fast.

## The problem it solves

Standing up a backend means gluing together a database, an auth system, file storage, and a realtime layer — each with its own config and gotchas. Proprietary BaaS solves it but locks your data into someone else's platform.

## What I like

- It's just Postgres underneath — no lock-in, take your database anywhere
- Auth, storage, realtime and edge functions in one coherent SDK
- Self-host it or use their cloud; the code is open either way

## One gripe

⚠️ The 'one platform for everything' surface is large — you inherit Postgres ops knowledge eventually, especially at scale.

## Verdict

For getting a real, scalable backend up in an afternoon without selling your soul to a proprietary cloud, Supabase is hard to beat.

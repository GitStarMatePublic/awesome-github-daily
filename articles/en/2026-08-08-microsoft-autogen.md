# AutoGen: Microsoft's framework for AI agents that talk to each other — 60k stars

![microsoft/autogen](https://opengraph.githubassets.com/live/microsoft/autogen)

> Python · CC-BY-4.0 · 60,426 stars on GitHub

AutoGen is Microsoft's open-source framework for building multi-agent AI systems — where multiple agents converse, critique, and collaborate to solve a task. At 60k+ stars, it's one of the foundational libraries in the agent space.

## The problem it solves

A single LLM call is a one-shot guess. Hard problems need iteration, review, and specialized roles — a planner, a coder, a critic. Wiring that multi-agent choreography by hand, with reliable message passing and tool use, is genuinely hard.

## What I like

- Clean abstractions for multi-agent conversations and roles
- Built-in tool use, code execution, and human-in-the-loop options
- Backed by Microsoft Research with a serious ecosystem behind it

## One gripe

⚠️ Multi-agent systems can be expensive and unpredictable — more agents means more tokens and more ways for a conversation to wander.

## Verdict

If you're building beyond a single prompt into real multi-agent collaboration, AutoGen is one of the most credible foundations to start from.

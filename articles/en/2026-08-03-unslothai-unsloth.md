# Unsloth: fine-tune an LLM 2x faster on a single GPU — 71k stars

![unslothai/unsloth](https://raw.githubusercontent.com/unslothai/unsloth/main/images/unsloth%20logo%20black%20text.png)

> Python · Apache-2.0 · 71,593 stars on GitHub

Unsloth makes fine-tuning and running LLMs dramatically faster and lighter — famously 2x faster with far less memory — so you can customize models on hardware you actually have. It's at 71k+ stars and beloved by the local-fine-tuning crowd.

## The problem it solves

Fine-tuning a model sounds simple until you meet the reality: out-of-memory errors, days-long training runs, and a cloud GPU bill that makes you question the whole idea. For most people, custom models felt out of reach.

## What I like

- Big speed and memory wins — fine-tune on a single consumer GPU
- Supports the latest open models fast as they drop
- Great notebooks and docs — genuinely approachable for first-timers

## One gripe

⚠️ It's still a training tool, not a magic button — you need a decent dataset and some understanding of fine-tuning to get good results.

## Verdict

If cloud GPU bills and OOM errors killed your fine-tuning ambitions, Unsloth is the project that puts custom models back within reach.

# PocketBase: your entire backend in a single file — 60k stars

![pocketbase/pocketbase](https://i.imgur.com/aCBbjKx.png)

> Go · MIT · 60,677 stars on GitHub

PocketBase is an open-source realtime backend packed into one portable file: database, auth, file storage, and admin UI included. At 60k+ stars, it's the 'ship a backend in minutes' tool for indie devs and small apps.

## The problem it solves

For a small app or prototype, spinning up Postgres + an auth service + file storage + an admin panel is wildly disproportionate effort. You spend the whole weekend on infra and never get to the actual product.

## What I like

- Literally one executable — download, run, you have a backend
- Auth, realtime, file storage and an admin UI all included
- Embeddable as a Go framework when you outgrow the defaults

## One gripe

⚠️ Single-file simplicity has limits — for massive scale or complex multi-service architectures, you'll eventually outgrow it.

## Verdict

For indie hackers and small apps, PocketBase is the fastest 'zero to working backend' on the board — no infra weekend required.

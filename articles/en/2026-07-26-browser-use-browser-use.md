# Browser Use: give your AI agent hands to actually click around the web — 109k stars

![browser-use/browser-use](https://github.com/user-attachments/assets/2ccdb752-22fb-41c7-8948-857fc1ad7e24)

> Python · MIT · 109,267 stars on GitHub

Browser Use lets AI agents actually operate a browser — click, type, navigate, extract — instead of just talking about it. At 109k+ stars, it's become a go-to for turning an LLM into something that gets real web tasks done.

## The problem it solves

LLMs are great at reasoning and hopeless at doing. The web is still mostly built for human clicks, so any 'agent that books me a flight' needs a reliable way to see the page and act on it — and brittle Selenium scripts break the moment a layout shifts.

## What I like

- Turns any LLM into a web-acting agent — click, fill, scrape
- Handles the messy DOM-to-intent mapping so you don't script every selector
- Works across models and integrates into agent frameworks

## One gripe

⚠️ Web automation is inherently fragile and can be slow; sites with heavy bot-detection or CAPTCHAs will still fight you.

## Verdict

If you want an agent that does things on the web instead of just describing them, Browser Use is the cleanest bridge from reasoning to clicking.

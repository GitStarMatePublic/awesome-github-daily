# LocalAI: a drop-in, self-hosted replacement for the OpenAI API — 48k stars

![mudler/LocalAI](https://github.com/user-attachments/assets/72eab1dd-8b93-4fc0-9ade-84db49f24962)

> Go · MIT · 48,471 stars on GitHub

LocalAI is an open-source engine that exposes an OpenAI-compatible API for models you run yourself — LLMs, image, audio and more — no GPU required. At 48k+ stars, it lets existing apps swap the cloud for localhost by changing one URL.

## The problem it solves

You built an app against the OpenAI API and now you're locked in: every request costs money and ships your users' data to a third party. Rewriting everything to use local models sounds like a huge migration.

## What I like

- Drop-in OpenAI-compatible API — often just change the base URL
- Runs LLMs, image and audio models; works on consumer hardware, no GPU needed
- Self-hosted and private — your data and prompts stay in-house

## One gripe

⚠️ Local models on modest hardware won't match frontier cloud model quality or speed — you're trading peak capability for privacy and cost.

## Verdict

If you want to cut the cord from the OpenAI API without rewriting your app, LocalAI is the near-drop-in, self-hosted swap that makes it easy.

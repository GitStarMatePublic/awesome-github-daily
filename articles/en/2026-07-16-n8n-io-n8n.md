# n8n just crossed 200k stars — the automation tool that ate Zapier's lunch

![n8n-io/n8n](https://user-images.githubusercontent.com/10284570/173569848-c624317f-42b1-45a6-ab09-f0ea3c247648.png)

> TypeScript · NOASSERTION · 200,661 stars on GitHub

n8n quietly became one of the most-starred developer tools on GitHub, sitting north of 200k stars. It's a fair-code workflow automation platform — and with native AI nodes, it's become the default way people wire LLMs into real business processes.

## The problem it solves

Every team hits the same wall: you need System A to talk to System B when event C happens. SaaS automation tools solve it, then bill you per task and lock your logic inside their cloud. The moment you need a custom function or self-hosting, you're stuck.

## What I like

- Self-hostable — your workflows and data stay on your infra
- 400+ integrations, plus a code node when you outgrow the presets
- Native AI/LangChain nodes make it a real agent-builder, not just glue

## One gripe

⚠️ The fair-code license isn't classic OSI open source — commercial restrictions apply if you resell it. Read the license before you build a business on top.

## Verdict

If you've ever rage-quit a per-task automation bill, n8n is the self-hosted answer — and the AI nodes make it far more than a Zapier clone.

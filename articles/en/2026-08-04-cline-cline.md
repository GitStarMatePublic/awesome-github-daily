# Cline: the autonomous coding agent that asks before it acts — 66k stars

![cline/cline](https://opengraph.githubassets.com/live/cline/cline)

> TypeScript · Apache-2.0 · 66,207 stars on GitHub

Cline is an autonomous coding agent available as an IDE extension, CLI, or SDK — one that plans, edits files, and runs commands, but checks in with you at each step. At 66k+ stars, it's a favorite for people who want agent power without losing control.

## The problem it solves

Fully autonomous agents can go rogue: rewrite half your repo, run a destructive command, burn tokens down a rabbit hole. But pure autocomplete is too timid for real tasks. The sweet spot — power with a human in the loop — is surprisingly rare.

## What I like

- Plans and acts, but requests approval before edits and commands
- Model-agnostic and open — bring your own provider
- Available as extension, CLI, or SDK, so it fits your workflow

## One gripe

⚠️ The human-in-the-loop approvals that make it safe also make it less 'set it and forget it' — that's the deliberate trade-off.

## Verdict

Cline hits the balance a lot of developers actually want: an agent capable enough to do real work, but polite enough to ask first.

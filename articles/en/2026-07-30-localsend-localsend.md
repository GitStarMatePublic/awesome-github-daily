# LocalSend: AirDrop for everyone, with zero cloud in the middle — 88k stars

![localsend/localsend](https://opengraph.githubassets.com/live/localsend/localsend)

> Dart · Apache-2.0 · 88,332 stars on GitHub

LocalSend is an open-source, cross-platform alternative to AirDrop that sends files directly between devices over your local network. 88k+ stars, no accounts, no servers, no internet required.

## The problem it solves

Moving a file between a phone and a laptop — especially across ecosystems — is absurdly annoying. You end up emailing it to yourself or uploading to some cloud, which means your private file takes a detour through a stranger's server.

## What I like

- Truly local: files go device-to-device over your own network
- Cross-platform — Android, iOS, Windows, macOS, Linux all included
- No account, no cloud, open source: nothing to trust but the code

## One gripe

⚠️ Both devices need to be on the same network and have the app — it's not a universal link you can send to anyone, anywhere.

## Verdict

For fast, private file transfers across every OS you own, LocalSend is the AirDrop replacement that finally doesn't care what brand your devices are.

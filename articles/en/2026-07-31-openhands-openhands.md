# OpenHands: an AI developer that opens PRs while you sleep — 84k stars

![OpenHands/OpenHands](https://assets.openhands.dev/logo-whitebackground.png)

> TypeScript · MIT · 84,076 stars on GitHub

OpenHands (formerly OpenDevin) is an open-source platform for AI software-development agents that can write code, run commands, browse, and open pull requests. At 84k+ stars, it's one of the most ambitious 'AI teammate' projects going.

## The problem it solves

Most coding assistants stop at suggesting code. But real dev work is a loop: read the repo, run the tests, hit an error, fix it, repeat. Handing an agent a whole task — not just autocomplete — needs a safe environment where it can actually execute.

## What I like

- Agents that execute: run commands, edit files, browse, open PRs
- Sandboxed environment so the agent can act without wrecking your machine
- Fully open source and self-hostable — you control the loop

## One gripe

⚠️ Autonomous agents still need a human reviewer; letting one run unattended on important code is asking for surprises. Treat its output as a draft.

## Verdict

OpenHands is the clearest open glimpse of the 'AI teammate that ships PRs' future — powerful, but keep a human on the merge button.

# Dify: the production platform for LLM apps, RAG and agents — 152k stars

![langgenius/dify](https://github.com/langgenius/dify/assets/13230914/5a17bdbe-097a-4100-8363-40255b70f6e3)

> TypeScript · NOASSERTION · 152,459 stars on GitHub

Dify is an open-source platform for building and running LLM applications — agentic workflows, RAG pipelines, and model management in one place. It's at 152k+ stars and is one of the most complete 'LLMOps' stacks around.

## The problem it solves

Going from a cool prompt to a production app means solving a dozen unglamorous problems: RAG ingestion, prompt versioning, observability, rate limits, multiple model providers. Stitching that together yourself burns weeks.

## What I like

- Agentic workflows + RAG + model management in one integrated stack
- Backend-as-a-service style: build an app and expose it via API fast
- Provider-agnostic — swap between dozens of model vendors

## One gripe

⚠️ It's a big, opinionated platform. For a tiny single-purpose bot it's heavier than you need — the payoff is at app/team scale.

## Verdict

When you're past prototypes and need to actually ship and operate an LLM app, Dify hands you most of the plumbing out of the box.

# Goose: an open, extensible AI agent that goes beyond code suggestions — 52k stars

![aaif-goose/goose](https://opengraph.githubassets.com/live/aaif-goose/goose)

> Rust · Apache-2.0 · 52,822 stars on GitHub

Goose is an open-source, on-machine AI agent that doesn't just suggest code — it executes tasks end to end using your tools, via extensions. At 52k+ stars, it's a fast-rising take on the local, extensible agent.

## The problem it solves

A suggestion is not a solution. Real automation needs an agent that can actually run your build, hit your APIs, and use your local tools — not one that stops at 'here's what you could type.' But you also don't want to hand a black box the keys to your machine.

## What I like

- Executes real tasks on your machine using your existing tools
- Extensible via a plugin system — teach it new capabilities
- Open source and model-flexible; runs locally, under your control

## One gripe

⚠️ An agent with real access to your machine and tools demands care — scope its permissions and keep an eye on what it runs.

## Verdict

For developers who want an extensible agent that actually does the work locally, Goose is a compelling, fast-growing open option.

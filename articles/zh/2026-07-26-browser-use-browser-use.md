# Browser Use：给你的 AI Agent 装上一双真能点网页的手，斩获 10.9 万 Star

![browser-use/browser-use](https://github.com/user-attachments/assets/2ccdb752-22fb-41c7-8948-857fc1ad7e24)

> Python · MIT · GitHub 已 109,267 star

Browser Use 让 AI Agent 真正去操作浏览器——点击、输入、导航、抽取——而不只是嘴上说说。10.9 万+ star，它成了把 LLM 变成「真能干活」的热门选择。

## 它解决什么问题

LLM 擅长推理，却对「动手」束手无策。网页至今主要为人类点击而建，所以任何「帮我订机票的 Agent」都需要一种可靠的方式去看懂页面并操作它——而脆弱的 Selenium 脚本，布局一变就崩。

## 我个人比较欣赏的几点

- 把任何 LLM 变成能操作网页的 Agent——点击、填写、抓取
- 帮你搞定 DOM 到意图的脏活，不用为每个选择器写脚本
- 跨模型可用，能接进各类 Agent 框架

## 一个小遗憾

⚠️ 网页自动化天生脆弱、还可能慢；重度反爬或带验证码的站点依然会跟你死磕。

## 小结

想要一个真能在网页上「做事」而不只是「描述」的 Agent，Browser Use 是从推理到点击之间最干净的那座桥。

# Hoppscotch：住在浏览器标签页里的极速开源 Postman 替代品，斩获 8 万 Star

![hoppscotch/hoppscotch](https://opengraph.githubassets.com/live/hoppscotch/hoppscotch)

> TypeScript · MIT · GitHub 已 80,032 star

Hoppscotch 是一个开源的 API 开发生态——轻量、飞快的 Postman 替代品，直接跑在浏览器里。8 万+ star，当 Postman 开始变重时，人们就伸手去够它。

## 它解决什么问题

Postman 变强了，也变重了——一整个应用、一个账号、一道登录墙、你没要的同步。有时你只想发个 HTTP 请求看看响应，不想要 300MB 的安装包加注册。

## 我个人比较欣赏的几点

- 即开即用又轻量——开个标签页就能测接口
- REST、GraphQL、WebSocket 等一网打尽，界面干净
- 开源可自托管，你的 API 集合始终归你

## 一个小遗憾

⚠️ 最深度的团队/企业协作功能，比 Postman 付费档还不够成熟——个人和小团队是它的甜点区。

## 小结

当 Postman 对「就测一下这个接口」显得杀鸡用牛刀时，Hoppscotch 就是那个你会真正钉在标签栏的极速开源页。

# Supabase：建在 Postgres 之上的开源 Firebase 替代品，坐拥 10.8 万 Star

![supabase/supabase](https://user-images.githubusercontent.com/8291514/213727234-cda046d6-28c6-491a-b284-b86c5cede25d.png#gh-light-mode-only)

> TypeScript · Apache-2.0 · GitHub 已 108,002 star

Supabase 给你一整套后端——Postgres 数据库、认证、存储、实时、边缘函数——既有 Firebase 的开发体验，又有 Postgres 的开放。10.8 万+ star，是快速上线的默认之选。

## 它解决什么问题

搭一个后端，要把数据库、认证系统、文件存储、实时层拼在一起，每个都有自己的配置和坑。闭源 BaaS 能解决，却把你的数据锁进别人的平台。

## 我个人比较欣赏的几点

- 底层就是 Postgres——不锁定，数据库随时可迁走
- 认证、存储、实时、边缘函数，统一在一套连贯的 SDK 里
- 可自托管也可用它的云；两种方式代码都开源

## 一个小遗憾

⚠️ 「一个平台什么都管」的面很大——规模上去后，你终究得补上 Postgres 的运维知识。

## 小结

想在一个下午搭起真正、可扩展的后端，又不把灵魂卖给闭源云，Supabase 很难被击败。

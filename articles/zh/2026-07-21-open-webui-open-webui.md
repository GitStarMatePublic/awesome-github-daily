# Open WebUI：给你自己的模型套上一个自托管 ChatGPT，揽获 14.8 万 Star

![open-webui/open-webui](https://opengraph.githubassets.com/live/open-webui/open-webui)

> Python · NOASSERTION · GitHub 已 148,812 star

Open WebUI 给你一个精致的、类 ChatGPT 的界面，完全跑在你自己的基础设施上，对接 Ollama 或任何 OpenAI 兼容 API。14.8 万+ star，是自托管 AI 人群的首选前端。

## 它解决什么问题

用 Ollama 在本地跑模型很爽——直到你想要一个带历史记录、多用户、文档上传和 RAG 的真正聊天界面。裸 API 是没法直接甩给不太懂技术的同事用的。

## 我个人比较欣赏的几点

- 干净的多用户聊天界面，带历史、角色和权限
- 本地（Ollama）和远程 OpenAI 兼容模型通吃
- 内置 RAG：丢进文档就能对着聊，不用额外服务

## 一个小遗憾

⚠️ 功能变多，也意味着部署不再是「就一个聊天框」那么简单——要留点时间做配置把各部分接好。

## 小结

想要 ChatGPT 的体验、又一个字节都不发给别人的云，Open WebUI 就是那个盖在你模型之上的前端。

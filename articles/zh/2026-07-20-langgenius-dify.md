# Dify：把 LLM 应用、RAG、Agent 一站式投产的平台，坐拥 15.2 万 Star

![langgenius/dify](https://github.com/langgenius/dify/assets/13230914/5a17bdbe-097a-4100-8363-40255b70f6e3)

> TypeScript · NOASSERTION · GitHub 已 152,459 star

Dify 是一个开源的 LLM 应用构建与运行平台——agentic 工作流、RAG 流水线、模型管理一处搞定。15.2 万+ star，是目前最完整的「LLMOps」技术栈之一。

## 它解决什么问题

从一个惊艳的 prompt 到一个生产应用，中间要解决十几个不光鲜的问题：RAG 入库、prompt 版本、可观测性、限流、多模型供应商。自己一个个拼起来，几周就没了。

## 我个人比较欣赏的几点

- Agentic 工作流 + RAG + 模型管理，整合在一套栈里
- 类 BaaS 风格：搭好应用快速以 API 暴露
- 不挑供应商——几十家模型厂商随意切换

## 一个小遗憾

⚠️ 它是个大而有主见的平台。做个单一用途的小 bot 会嫌它重——它的价值在应用级/团队级规模上。

## 小结

当你过了原型阶段、要真正把 LLM 应用投产并运维时，Dify 开箱就把大部分管道给你铺好了。

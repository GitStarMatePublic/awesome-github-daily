# AutoGen：微软的多智能体协作框架，让 AI 之间互相对话，斩获 6 万 Star

![microsoft/autogen](https://opengraph.githubassets.com/live/microsoft/autogen)

> Python · CC-BY-4.0 · GitHub 已 60,426 star

AutoGen 是微软开源的多智能体 AI 框架——让多个 Agent 对话、互相批评、协作解决一个任务。6 万+ star，是 Agent 领域的基石库之一。

## 它解决什么问题

单次 LLM 调用是一锤子的猜测。难题需要迭代、审阅和分工角色——一个规划者、一个写码者、一个批评者。手工编排这套多智能体协作，还要可靠的消息传递和工具调用，是真的难。

## 我个人比较欣赏的几点

- 为多智能体对话和角色提供干净的抽象
- 内置工具调用、代码执行，以及人在环中的选项
- 微软研究院背书，背后生态相当扎实

## 一个小遗憾

⚠️ 多智能体系统可能昂贵且不可预测——Agent 越多，token 越多，对话跑偏的方式也越多。

## 小结

如果你要超越单个 prompt、做真正的多智能体协作，AutoGen 是最可信的起点框架之一。

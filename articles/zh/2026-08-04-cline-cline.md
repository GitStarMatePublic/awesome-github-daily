# Cline：动手前会先问你一声的自主编程 Agent，斩获 6.6 万 Star

![cline/cline](https://opengraph.githubassets.com/live/cline/cline)

> TypeScript · Apache-2.0 · GitHub 已 66,207 star

Cline 是一个自主编程 Agent，提供 IDE 插件、CLI 和 SDK 三种形态——它会规划、改文件、跑命令，但每一步都跟你确认。6.6 万+ star，深受「想要 Agent 的能力又不想失控」的人喜爱。

## 它解决什么问题

全自主 Agent 可能失控：重写你半个仓库、跑个毁灭性命令、钻牛角尖烧光 token。但纯自动补全又太胆小，干不了真活。「有能力又有人把关」这个甜点区，意外地稀缺。

## 我个人比较欣赏的几点

- 会规划会动手，但改文件、跑命令前会请求批准
- 不挑模型且开源——自带 provider
- 插件、CLI、SDK 三形态，适配你的工作流

## 一个小遗憾

⚠️ 让它安全的「人在环中」审批，也让它没那么「设好就不用管」——这是有意的取舍。

## 小结

Cline 恰好击中很多开发者真正想要的平衡：能干真活，又懂礼貌先问一声。

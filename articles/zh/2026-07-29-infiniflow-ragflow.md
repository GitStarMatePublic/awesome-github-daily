# RAGFlow：真正读得懂你那堆脏文档的 RAG 引擎，斩获 8.8 万 Star

![infiniflow/ragflow](https://opengraph.githubassets.com/live/infiniflow/ragflow)

> Go · Apache-2.0 · GitHub 已 88,447 star

RAGFlow 是领先的开源检索增强生成（RAG）引擎，把深度文档理解和 Agent 能力融在一起。8.8 万+ star，它专攻 RAG 最难的那部分：从丑陋的真实文件里抽出干净、准确的上下文。

## 它解决什么问题

朴素 RAG 把 PDF 盲切成 512-token 的片段然后祈祷。表格被撕碎、排版丢失，模型还自信地引用了垃圾。让你的 RAG 应用出错的，往往是检索质量，而不是模型。

## 我个人比较欣赏的几点

- 深度文档解析，尊重表格、排版和结构
- 带出处的引用，答案能溯源回原文
- 把 RAG 和 Agent 工作流融合，支持对数据多步推理

## 一个小遗憾

⚠️ 相比「裸向量库+prompt」，它是个更重、更有主见的引擎——前期要跑的和要理解的东西更多。

## 小结

当拖垮你 RAG 应用的是检索质量时，RAGFlow 的文档理解才是真正能扭转局面的那次升级。

# n8n 突破 20 万 Star！这个把 Zapier 拉下马的自动化神器，现在还能编排 AI

![n8n-io/n8n](https://user-images.githubusercontent.com/10284570/173569848-c624317f-42b1-45a6-ab09-f0ea3c247648.png)

> TypeScript · NOASSERTION · GitHub 已 200,661 star

n8n 悄悄成了 GitHub 上 star 最高的开发者工具之一，已突破 20 万。它是一个 fair-code 的工作流自动化平台，而随着原生 AI 节点的加入，它成了很多人把大模型接进真实业务流程的默认选择。

## 它解决什么问题

每个团队都会撞上同一堵墙：当事件 C 发生时，你需要系统 A 和系统 B 对话。SaaS 自动化工具能解决，然后按任务量收你钱，还把你的业务逻辑锁在它的云里。一旦你要自定义函数或自托管，就卡死了。

## 我个人比较欣赏的几点

- 可自托管——工作流和数据都留在你自己的机器上
- 400+ 集成，预设不够用时还有 code 节点兜底
- 原生 AI / LangChain 节点，让它是个真正的 agent 搭建器，不只是胶水

## 一个小遗憾

⚠️ fair-code 协议并非经典的 OSI 开源，若你要转售它有商业限制。真拿它做生意前，先把协议读清楚。

## 小结

如果你曾被按任务计费的自动化账单气到弃用，n8n 就是那个自托管的答案——而 AI 节点让它远不止是个 Zapier 克隆。

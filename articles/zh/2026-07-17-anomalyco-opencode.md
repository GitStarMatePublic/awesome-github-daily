# opencode：不绑定任何编辑器的开源编程 Agent，狂揽 19.7 万 Star

![anomalyco/opencode](https://opengraph.githubassets.com/live/anomalyco/opencode)

> TypeScript · MIT · GitHub 已 197,581 star

opencode 是一个终端优先、完全开源的编程 Agent，star 已冲过 19.7 万。它的主张很简单：一个活在你终端里的 Agent，兼容任何模型，不绑定某个 IDE 或厂商。

## 它解决什么问题

大多数 AI 编程 Agent 都想霸占你的整个环境——它的编辑器、它的模型、它的订阅。如果你钟爱现有的终端工作流，这就很难接受。而在「帮你写代码」这件事上被厂商锁定，风险是实打实的。

## 我个人比较欣赏的几点

- 终端原生——直接融入你已有的工作流
- 不挑模型：自带 provider，不强制订阅
- 完全开源，Agent 本身可审计、可扩展

## 一个小遗憾

⚠️ 终端优先意味着没有花哨的 GUI 保姆式引导——想要精致的点点点 IDE 体验，这个（有意）不提供。

## 小结

对于住在终端里、拒绝被某一家编程 Agent 锁死的开发者，opencode 就是那个开放的答案。

# OpenHands：趁你睡觉就把 PR 提了的 AI 开发者，斩获 8.4 万 Star

![OpenHands/OpenHands](https://assets.openhands.dev/logo-whitebackground.png)

> TypeScript · MIT · GitHub 已 84,076 star

OpenHands（前身 OpenDevin）是一个开源的 AI 软件开发 Agent 平台，能写代码、跑命令、浏览网页、提 pull request。8.4 万+ star，是「AI 队友」方向最有野心的项目之一。

## 它解决什么问题

大多数编程助手止步于「建议代码」。但真正的开发是个循环：读仓库、跑测试、撞报错、修、再来。把一整个任务——而不只是自动补全——交给 Agent，需要一个它真能执行命令的安全环境。

## 我个人比较欣赏的几点

- 会执行的 Agent：跑命令、改文件、浏览、提 PR
- 沙箱环境，Agent 动手也不会毁了你的机器
- 完全开源可自托管——循环由你掌控

## 一个小遗憾

⚠️ 自主 Agent 仍需人来 review；让它无人看管地跑重要代码，等于自找惊喜。把它的产出当草稿看。

## 小结

OpenHands 是「会提 PR 的 AI 队友」这个未来最清晰的开源一瞥——很强，但合并按钮上得留个人。

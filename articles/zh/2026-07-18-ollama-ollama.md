# Ollama：一行命令在本地跑最强开源大模型，已收割 17.8 万 Star

![ollama/ollama](https://github.com/ollama/ollama/assets/3325447/0d0b44e2-8f4a-4e99-9b52-a5c1c741c8f7)

> Go · MIT · GitHub 已 178,523 star

Ollama 把「在自己机器上跑开源大模型」从一个周末的 CUDA 折磨，变成了一行命令。17.8 万+ star，它已是开发者在本地跑 Kimi、GLM、DeepSeek、Llama 的事实标准。

## 它解决什么问题

以前跑本地模型意味着跟 Python 环境、GPU 驱动、量化格式和散落在五个仓库里的权重搏斗。大多数人放弃了，直接付 API 账单——哪怕那些任务根本不需要上云。

## 我个人比较欣赏的几点

- `ollama run <模型>`——真·一行命令，从零到开聊
- 干净的本地 API，你的应用打 localhost 而不是付费端点
- 模型库巨大，新开源权重一出就快速跟进

## 一个小遗憾

⚠️ 你还是得有硬件。大模型吃内存/显存，普通笔记本上只能跑较小的量化版本。

## 小结

如果你一直在为本可以本地跑的任务租算力，Ollama 就是那个一行命令的解法——私密、离线、跑起来免费。

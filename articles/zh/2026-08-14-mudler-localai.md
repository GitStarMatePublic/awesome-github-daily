# LocalAI：可直接替换 OpenAI API 的自托管引擎，斩获 4.8 万 Star

![mudler/LocalAI](https://github.com/user-attachments/assets/72eab1dd-8b93-4fc0-9ade-84db49f24962)

> Go · MIT · GitHub 已 48,471 star

LocalAI 是一个开源引擎，为你自己运行的模型——LLM、图像、音频等——暴露出兼容 OpenAI 的 API，还不需要 GPU。4.8 万+ star，让现有应用只改一个 URL，就把云换成 localhost。

## 它解决什么问题

你照着 OpenAI API 建好了应用，如今被锁定了：每个请求都花钱，还把用户数据送给第三方。把一切重写成用本地模型，听着像一场大迁移。

## 我个人比较欣赏的几点

- 可直接替换的 OpenAI 兼容 API——往往只改个 base URL
- 能跑 LLM、图像、音频模型；消费级硬件即可，不需 GPU
- 自托管且私密——数据和 prompt 都留在自家

## 一个小遗憾

⚠️ 普通硬件上的本地模型，质量和速度比不了前沿云模型——你是在用峰值能力换隐私和成本。

## 小结

如果你想摆脱对 OpenAI API 的依赖又不想重写应用，LocalAI 就是那个近乎即插即用、让切换变简单的自托管替代。

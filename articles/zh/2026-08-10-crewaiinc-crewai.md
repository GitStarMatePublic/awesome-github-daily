# CrewAI：像带团队一样编排一群扮演角色的 AI Agent，斩获 5.7 万 Star

![crewAIInc/crewAI](https://img.youtube.com/vi/-kSOTtYzgEw/hqdefault.jpg)

> Python · MIT · GitHub 已 57,088 star

CrewAI 是一个编排自主 AI Agent 的框架——让它们各司其职、像团队一样协作：一个研究员、一个写手、一个审阅者，一起攻一个任务。5.7 万+ star，是搭建 agentic 工作流最流行的方式之一。

## 它解决什么问题

让一个模型「什么都干」，产出往往稀松平庸。真活受益于分工与专业化——但协调多个 Agent、它们的工具、以及彼此如何交接工作，是个实打实的工程问题。

## 我个人比较欣赏的几点

- 直观的「角色小队」心智模型——好推理
- 每个 Agent 有自己的目标、工具和人设，产出更聚焦
- 精简且独立——不焊死在某个庞大框架上

## 一个小遗憾

⚠️ 和所有多智能体方案一样，成本和延迟会叠加，Agent 越多，计划跑偏的地方也越多。

## 小结

如果「专家团队」这个比喻让你一下就懂，CrewAI 是通往真正 agentic 工作流最好上手的入口之一。

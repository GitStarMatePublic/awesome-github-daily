# AnythingLLM：一体化、对着自己文档聊天的私有 ChatGPT，斩获 6.4 万 Star

![Mintplex-Labs/anything-llm](https://github.com/Mintplex-Labs/anything-llm/blob/master/images/wordmark.png?raw=true)

> JavaScript · MIT · GitHub 已 64,720 star

AnythingLLM 是一个全栈的私有 AI 应用：用任意 LLM 对着你自己的文档聊天，内置 RAG、Agent，数据不出你的掌控。6.4 万+ star，是「拥有你的智能」而非「租一个聊天机器人」的答案。

## 它解决什么问题

把公司机密文档传进别人的聊天机器人是合规噩梦，可从零搭自己的 RAG 栈又要几周。多数团队卡在「不安全但省事」和「安全但永远上不了线」之间。

## 我个人比较欣赏的几点

- 带 RAG 对着文档聊天，完全可自托管
- 本地或商业模型都能用——供应商你说了算
- 多用户工作区，整个团队都能私密使用

## 一个小遗憾

⚠️ 一体化意味着有主见的默认；深度定制的 RAG 流水线，可能还是想要更可组合、代码优先的栈。

## 小结

对于想要一个「对着我们文档聊天的私有 ChatGPT」又不想自己铺管道的团队，AnythingLLM 是最快抵达那里的安全路径。

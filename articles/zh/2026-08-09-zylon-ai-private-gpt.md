# PrivateGPT：全程断网也能问你的文档，斩获 5.7 万 Star

![zylon-ai/private-gpt](https://opengraph.githubassets.com/live/zylon-ai/private-gpt)

> Python · Apache-2.0 · GitHub 已 57,445 star

PrivateGPT 是一套完整的 API 层，用来在你自己的文档上构建私密、离线的 AI 应用——数据永不离开你的机器。5.7 万+ star，它是最早一批「对着文件聊天、100% 本地」的项目，至今仍是参考实现。

## 它解决什么问题

「用 AI 处理你的文档」这个承诺，在「你的文档」被上传到第三方 API 的那一刻就崩了。对法律、医疗、或就是单纯私密的数据，这根本行不通——可自己搭本地流水线又让人发怵。

## 我个人比较欣赏的几点

- 100% 离线选项——文档和查询都不出你的机器
- 干净的 API 层，可在其上构建私有 AI 应用
- 久经考验，是本地 RAG 模式被广泛引用的范本

## 一个小遗憾

⚠️ 纯本地意味着本地性能——没有 GPU 时，面对大文档集，响应可能偏慢。

## 小结

当「私密」是硬性要求而非加分项时，PrivateGPT 是全离线文档 AI 那个经过验证的起点。

# ComfyUI：AI 绘画高手真正在用的节点式 GUI，收割 12.7 万 Star

![Comfy-Org/ComfyUI](https://github.com/user-attachments/assets/36e065e0-bfae-4456-8c7f-8369d5ea48a2)

> Python · GPL-3.0 · GitHub 已 127,653 star

ComfyUI 是最强大、最模块化的扩散模型 GUI，核心是一张可视化节点图。12.7 万+ star，当简单滑块不够用时，认真的 Stable Diffusion / 图像生成用户都往这来。

## 它解决什么问题

基础的图像生成 UI 把一切都藏在一个 prompt 框和几个滑块后面。可一旦你想要真正的流水线——controlnet、放大、自定义采样、可复现工作流——就撞上一堵看不穿的墙。

## 我个人比较欣赏的几点

- 节点图把整条流水线摊开——完全掌控，毫无隐藏
- 工作流就是可分享的文件：一比一复现别人的配置
- 模块化可扩展，自定义节点生态庞大

## 一个小遗憾

⚠️ 强大的代价是陡峭的学习曲线——第一天面对节点图会发怵，做简单任务又嫌杀鸡用牛刀。

## 小结

如果你已经玩腻了一键出图、想真正「工程化」你的流水线，ComfyUI 就是那个值得爬学习曲线的专业工具。

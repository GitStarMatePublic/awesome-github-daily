# Unsloth：单张显卡把大模型微调提速一倍，斩获 7.1 万 Star

![unslothai/unsloth](https://raw.githubusercontent.com/unslothai/unsloth/main/images/unsloth%20logo%20black%20text.png)

> Python · Apache-2.0 · GitHub 已 71,593 star

Unsloth 让微调和运行大模型显著更快、更省——著名的「快一倍、省一大截显存」——让你在真正拥有的硬件上定制模型。7.1 万+ star，深受本地微调人群喜爱。

## 它解决什么问题

微调一个模型听着简单，直到你撞上现实：爆显存、跑几天的训练、以及一张让你怀疑人生的云 GPU 账单。对大多数人来说，定制模型曾遥不可及。

## 我个人比较欣赏的几点

- 速度和显存双赢——单张消费级显卡就能微调
- 新开源模型一出就快速支持
- notebook 和文档都很好——新手也真能上手

## 一个小遗憾

⚠️ 它终究是个训练工具，不是魔法按钮——想出好结果，你得有像样的数据集和一点微调常识。

## 小结

如果云 GPU 账单和爆显存扼杀了你微调的念头，Unsloth 就是那个把定制模型重新拉回你触手可及范围的项目。

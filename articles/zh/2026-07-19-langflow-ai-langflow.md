# Langflow：拖拖拽拽就搭出一个能跑的 AI Agent，斩获 15.3 万 Star

![langflow-ai/langflow](https://github.com/user-attachments/assets/03168b17-a11d-4b2a-b0f7-c1cce69e5a2c)

> Python · MIT · GitHub 已 153,244 star

Langflow 是一个可视化、低代码的 AI 应用与 Agent 搭建器，已揽获 15.3 万+ star。你在画布上把 prompt、模型、工具和数据源连起来，然后整套导出成 API。

## 它解决什么问题

用纯代码搭 LLM 流水线，光样板代码就写一堆，还没验证想法能不能成。靠「写代码-部署-测试」循环去调 prompt 和链路太慢——尤其当非工程师同事也想改逻辑时。

## 我个人比较欣赏的几点

- 可视化画布，链路和 Agent 逻辑一眼看懂
- 直接以 API 交付，原型不重写就变后端
- 组件库庞大——模型、向量库、工具，即拖即用

## 一个小遗憾

⚠️ 可视化搭建有天花板：非常定制的逻辑最终还是落到 code 节点，复杂流程在画布上容易连成意大利面。

## 小结

论快速原型、论让不写代码的人也能塑造 AI 逻辑，Langflow 是最干净的可视化搭建器之一。
